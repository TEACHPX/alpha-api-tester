# Contributing to PULSE API X

Thanks for helping improve PULSE API X!

## Development

1. Fork the repository.
2. Create a feature branch:
   ```bash
   git checkout -b feature/my-feature
   ```
3. Create a virtual environment and install dependencies.
4. Make your changes.
5. Test the application locally.
6. Commit with a clear message.
7. Push your branch and open a pull request.

## Good practices

- Keep changes focused.
- Avoid committing secrets, tokens or local databases.
- Prefer simple, readable Python and JavaScript.
- Update documentation when behavior changes.
- Explain security-sensitive changes clearly in the pull request.

## Commit examples

```text
feat: add response diff viewer
fix: handle invalid JSON headers
docs: improve Termux installation guide
refactor: simplify request history storage
```
