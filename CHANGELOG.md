# Changelog

## 1.0.0 — 2026-10-05

### Added

- Advanced request laboratory
- GET, POST, PUT, PATCH, DELETE, HEAD and OPTIONS support
- JSON/raw request bodies
- Header editor
- Environment variables with `{{variable}}` syntax
- Saved requests / collections
- Request history
- Response status, timing and size metrics
- Pretty/raw/header response inspector
- cURL generation and copy
- SQLite persistence
- JSON export
- Responsive neon/glass interface
- GitHub-ready documentation
